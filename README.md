# ANA特典航空券 必要マイル計算アプリ

ANA特典航空券の必要マイル数を、シーズン別にすばやく計算できるWebアプリです。

🔗 **アプリを開く:** https://takeya-createj.github.io/ana-mile-calc/

## できること

- **国内線（直行）** — 全国65空港から選択。ANA公式の区間区分で必要マイルを自動判定
- **国内線（沖縄離島・那覇乗継）** — 「1区間ずつ合算」と「沖縄離島4区間チャート」を比較し、お得な方を表示
- **国際線** — 国・地域から選ぶとゾーンを自動判定。往復は往路・復路それぞれのシーズンで計算
- 往復は往路・復路の日付を別々に入力し、ANA公式ルールで必要マイルを合算
- 搭乗日を入れると該当シーズン（L／R／H）を自動でハイライト

## 注意

- 必要マイル数・区間・シーズンは [ANA公式](https://www.ana.co.jp/ja/jp/guide/amc/award/) のチャート（2024/10/27改定後）に基づきます。
- シーズン日付の一部（2026年後半〜2027年）は補完値です。**最終的な必要マイル・空席は必ずANA公式でご確認ください。**

## 更新方法

`index.html` 後半の `SEASON_DATA` の日付を書き換えれば、シーズン期間を最新化できます。
